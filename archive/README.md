# Historical source material

The current article is supported by the derived data, saved partitions, numerical results and portable scripts linked from the repository root.

`analysis_source/` preserves selected original analysis implementations. These files document the original workflow and contain historical directory assumptions. Use the entry points in `src/` for repository-relative verification and replay.

`previous_materials/` preserves the earlier public organization of the repository, including historical figures, community worksheets and methodological notes. These materials retain their original file identities for provenance. They should be read with their recorded scope and version; the current cumulative 2015-2022 input contains 1,499 records and is identified in the current graph index and supplementary tables.

Earlier Git history remains available. Moving files into this archive does not turn a historical layout, worksheet label or community identifier into an independent validation of a current finding.
